Cuaderno de relación · Escuela de Eudemonía

Código original del piloto integrado en eudemonia.es/cuaderno-relacion/.
Base conceptual: Aaron T. Beck, Con el amor no basta. Preguntas y agrupación originales; versión exploratoria pendiente de revisión profesional.

Desarrollo
  node tools/cuaderno-relacion/test.mjs
  npm run build

El build genera public/cuaderno-relacion/aplicacion.html, la copia sin conexión y las fuentes Poppins locales. Astro genera la ruta principal con Base.astro y analytics=false; el marco de mismo origen mantiene aislados los estilos del cuaderno. El directorio generado está ignorado por Git.

No necesita backend, cuentas, claves ni API de IA. Las respuestas están en memoria del navegador. Borradores e informes se guardan cifrados mediante descarga voluntaria. El módulo sexual, las respuestas detalladas y los textos libres requieren elecciones adicionales para compartir.

Se puede trabajar individualmente sin participación de la pareja, o sumar después una segunda perspectiva. La comparación exige archivos compatibles, código y periodo coincidentes. No hay nota global, percentiles ni diagnóstico automático.

El logo de la Fundación es una copia exacta de su original, autorizado por Pablo. No se ha recreado.
